# Owla backup bundle

This folder is the second-layer backup for Owla.

## Contains
- `profile/` — personality and profile config snapshots
- `calendar/` — calendar tool code
- `style/` — Telegram post writing guide
- `skills/` — writing skill snapshot

## What should go here over time
- profile updates
- new skills or skill snapshots
- non-secret tool code
- writing style updates

## What must not go here
- API keys
- bot tokens
- app-specific passwords
- any `.env` secrets
