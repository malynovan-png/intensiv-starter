# Telegram post style guide for Owla

This note is the working basis for writing Natalie's Telegram posts.

## General principles

- Write in a warm, expert, conversational tone.
- Keep it clear, structured, and easy to copy into Telegram.
- Use short paragraphs and visually separated blocks.
- Prefer examples over theory.
- Use emojis lightly but intentionally.
- Keep the language lively, not academic.
- If the topic is educational, explain simply and concretely.
- If the topic is a personal/event post, sound sincere and natural.
- If the user asks: **"напиши тг пост на тему..."**, choose the most suitable rubric automatically if the user did not name one.
- For grammar posts, prefer a clean greeting like **"Hello, Darlings 💕"** instead of overly chatty openings when the tone should stay teacher-like.
- For grammar posts, prefer natural-sounding English examples; avoid awkward affirmative `much` sentences like `There is much water in the bottle.` — use more natural phrasing such as `There is a lot of water in the bottle.`
- Keep the educational post structure, but make the opening line a bit more polished and brand-consistent when the user asks for a Telegram channel post.

## Core rubrics

### 1) Grammar post

Used for grammar explanations, vocabulary rules, or mini-lesson posts.

**Typical structure**
- Hook title with emoji
- Short intro
- Main rule split into small blocks
- Examples with translation
- Short takeaway / cheat sheet
- Interactive question
- 2–3 relevant hashtags

**Style**
- Short and clear
- Teacher-like, but friendly
- No long academic paragraphs
- Use bullet points or compact blocks

**Target length**
- Usually 1200–1800 characters
- Short version is okay if the topic is simple

**Important elements**
- Examples are mandatory
- End with a small recap
- End with a CTA or question to readers

---

### 2) Event / impression post

Used for museum visits, trips, school activities, events, personal reflections.

**Typical structure**
- Warm intro with context: where / when / what happened
- Main emotional or educational part
- One insight or takeaway
- Closing thought or invitation to comment
- Optional hashtags

**Style**
- Personal, warm, sincere
- Like a real first-person story
- Can include educational bridge if relevant
- Emoji atmosphere is welcome

**Target length**
- About 250–350 words

---

### 3) English Life post

Used for real-life English phrases from everyday situations.

**Typical structure**
- Title like `📱 English Life: [topic]`
- Very short intro about the situation
- 5–10 useful phrases
- Each phrase with Russian translation
- Optional extra slang / idiom / bonus word
- Short final question or soft CTA

**Style**
- Cozy, real-life, practical
- Not theoretical
- Very useful and copy-friendly
- Often includes UK/US difference when relevant

**Target length**
- One Telegram screen
- Usually 5–10 phrases only

**Must include**
- Translation for every phrase
- One bonus word or idiom when useful
- A short closing question

---

### 4) Series / idiom / tricky phrase post

Used for phrases from series, idioms with a twist, or expressions that mislead beginners.

**Typical structure**
- Hook title
- The phrase itself
- Why it looks simple / misleading
- Real meaning in Russian
- Small case example or dialogue
- Memory tip / rule of thumb
- CTA at the end

**Style**
- Short, sharp, a little playful
- Expert but friendly
- No water
- Show the trick clearly

**Target length**
- 100–180 words
- Usually one Telegram screen

**Must include**
- The real meaning
- A quick example
- A memory anchor
- CTA / engagement prompt

## Formatting habits

- Use short lines.
- Break up dense content into blocks.
- Use bullets or numbered items for rules.
- Put examples on separate lines.
- Use emoji as visual markers, not decoration for decoration's sake.
- Avoid tables in Telegram unless absolutely necessary.
- Avoid giant paragraphs.

## What to do when the user asks for a post

If Natalie writes something like:
- `напиши тг пост на тему ...`
- `сделай пост для канала ...`
- `собери пост по этой теме ...`

Then:
1. Identify the most likely rubric.
2. If the rubric is obvious, write immediately.
3. If the rubric is ambiguous, ask one short clarifying question only.
4. Keep the output aligned with the matching structure above.

## Tone reminders

- Expert, but friendly.
- Clear, but not dry.
- Practical, but not boring.
- Warm, but not overly sentimental.
- Concise, but not too thin.
