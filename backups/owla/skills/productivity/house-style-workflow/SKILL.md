# House style workflow

Use this skill when Natalie asks for Telegram or Instagram copy, parent-facing announcements, or Task-list handling.

## When to Use
- Write or rewrite Telegram posts, lesson posts, event announcements, or parent messages.
- Format Task-list output, add new items, or mark items done.
- Respond to prompts like "напиши пост в тг", "покажи таск лист", "добавь в Task-list", or similar variants.

## Core Style
- Mirror mixed Russian-English when Natalie uses it.
- Return ready-to-copy text first; avoid meta commentary unless asked.
- Prefer short paragraphs, concrete detail, and a warm direct voice.
- Keep the copy readable aloud and avoid making it sound like corporate promo.
- For back-to-school and life-event posts, use an all-caps hook when it fits and end with autumn emojis when relevant.
- Replace long dashes with hyphen-minus in final copy.
- Do not add a closing offer like "if you want, I can..." unless Natalie asks for variants.

## Telegram Posts
### Life event posts
- Start with a hook that names the moment.
- Add a short emotional or situational setup.
- Describe one concrete scene or detail.
- End with a short reflective or motivating line.

### Grammar posts
- Use a catchy emoji title.
- Keep the intro short.
- Explain in 2–4 clear blocks.
- Use examples with translations.
- Finish with a short takeaway, question, or mini-cheat-sheet.
- Use -? no, use the user's preferred bullet style in examples and lists.

### Phrases from series / with a twist
- Show the phrase.
- Briefly say how it sounds at first glance.
- Explain the real meaning.
- Add a short example or mini-dialogue.
- End with a memory tip and CTA.

## Task-list Rules
- Use two categories only: BUSINESS and PERSONAL.
- Put completed items at the top within their category.
- Mark completed items as `✅ ~~text~~`.
- Keep completed items in the list until the next day.
- Show only the list itself; if clarification is needed, ask in a separate message.
- Add new tasks with a matching emoji by meaning.

## Output Rules
- For posts: output the final text only.
- For Task-list: output the list only.
- If the request is ambiguous, ask one short clarifying question and wait.
