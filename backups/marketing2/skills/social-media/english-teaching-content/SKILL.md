# English teaching content

Use this skill when the user asks for educational content about English for school students or young learners, especially Telegram posts, captions, hooks, and short video scripts.

## What this skill covers

- Telegram posts about grammar, vocabulary, idioms, and common mistakes
- short hooks for Reels and TikTok
- clear explanations for school students
- soft, natural CTAs
- platform adaptation for Telegram, Instagram, Reels, and TikTok

## Reference files

See `references/session-notes.md` for session-specific patterns, example hooks, and the preferences captured from recent work.

## Default style

Write in Russian unless the user asks for another language.

Tone:
- аккуратно
- профессионально
- ясно
- живо

Rules:
- keep paragraphs short
- avoid tables unless the user asks for them
- use examples when explaining language points
- keep hooks modern and direct
- avoid cringe, emoji spam, and motivational fluff
- do not over-explain when the user asks for a short format
- make examples easy to remember aloud
- keep the teacher voice warm, not lecturing

## Core workflow

1. Identify the target platform and audience.
2. Choose the smallest useful structure for the format.
3. Explain the rule or idea in plain language first.
4. Add one or more concrete examples.
5. End with a soft CTA when appropriate.

## Structure by format

### Telegram post
Use:
- hook
- explanation
- example
- takeaway
- soft CTA

### Instagram caption
Use:
- stronger hook
- compact explanation
- one or two examples
- short closing line

### Reels or TikTok
Use:
- very short hook
- one clear idea per beat
- spoken rhythm
- easy-to-voice lines
- minimal clutter

## Hook patterns

Use hooks that feel current and clear.

Good hook styles:
- direct pain point: "Вот где школьники чаще всего путаются"
- contradiction: "Тема простая, а ошибок в ней много"
- promise: "Сейчас объясню так, чтобы запомнилось"
- teacher-first angle: "Если ученик путает это, причина обычно одна"
- light bilingual hook when it fits: "Hello, Darlings 💕 Вот тема, которую лучше не усложнять"

## English-teaching patterns

When the topic is grammar, vocabulary, or idioms:
- explain the rule in plain language first
- show the difference with a real example
- prefer school-friendly phrasing
- make the example easy to repeat out loud
- if useful, add a tiny contrast like correct / incorrect
- keep the explanation tied to use, not labels

## Media-based / series-based content

When the user wants phrases from series, films, clips, or subtitles:
- open with a context-based trigger that fits the scene or meaning
- do not force nostalgia as the default hook; use it only if the source naturally calls for it
- lead with the promise of what the phrase really means in context
- keep the lesson anchored to how people actually say it on screen
- let the clip or scene carry emotion, then explain the phrase
- favor the idea of living / real English over textbook wording

## Post templates

### Educational post
Use when the user wants to explain one grammar or vocabulary point.

Structure:
- hook
- simple explanation
- 2-3 examples
- takeaway
- soft CTA

### Mistake breakdown
Use when the user wants to show common student mistakes.

Structure:
- hook with a common error
- what is wrong
- how to say it correctly
- one short note why it matters
- soft CTA

### Quick tip post
Use when the user wants something short and light.

Structure:
- very short hook
- one clear tip
- one example
- one-line takeaway
- micro CTA

## CTA patterns

Use soft CTAs such as:
- "Если хочешь, я разберу ещё один пример."
- "Напиши в комментариях, и я сделаю продолжение."
- "Если нужно, я могу адаптировать это в Reels-сценарий."
- "Могу ещё сделать короткую версию для сторис."

## Anti-cringe rules

- Do not overhype simple ideas.
- Avoid cute or forced wording.
- Avoid sounding like a motivational speaker.
- Avoid too many exclamation marks.
- Avoid emojis unless they clearly fit the tone.
- Avoid generic endings like "Exciting times ahead".
- Avoid filler such as "Let’s dive in" or "Here’s what you need to know".

## Quality check

Before sending, check that the post:
- sounds natural aloud
- is easy to scan
- stays on topic
- has a clear ending
- matches the user’s requested tone
- fits the intended platform
