# Backup профиля marketing2 (Санса)

GitHub-safe snapshot локальных специализированных навыков контент-агента.

## Включено

- Навыки для образовательного и социального контента.
- Шаблоны визуального бренда, каруселей и Reels.
- Анализ профиля и контент-система преподавателя.
- Контент Starlight и английского языка.

## Не включено

- `.env` и MCP-токены.
- Telegram credentials.
- Кэш, логи, сессии и runtime-state.
- Встроенные skills Hermes, которые могут быть установлены заново.

Источник живого профиля: `marketing2`.
