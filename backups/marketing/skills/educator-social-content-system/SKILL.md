# Educator social content system

Use this skill when the user asks for educational social content for a personal brand: Telegram posts, Instagram captions, Reels hooks, Stories, carousels, monthly plans, worksheets, or visual direction.

## When to Use

Use for:
- teaching posts and captions
- educational carousels
- Reels and TikTok hooks or scripts
- Stories sequences
- content plans and rubric ideas
- print-friendly worksheets and cheat sheets
- brand-consistent visual prompts

Do not use for:
- unrelated corporate copy
- generic marketing blurbs without a teaching angle
- pure visual design work without content

## Prerequisites

Before writing, confirm:
- platform
- format
- topic
- audience level
- desired tone
- brand notes, if available

If brand notes exist, load them first and keep them active while writing.

## How to Run

1. Identify the platform and format.
2. Pick one core message.
3. Choose the right structure for the format.
4. Write in the user's voice with concrete examples.
5. Check that the piece feels natural aloud.
6. Add CTA and visual guidance only if the user asked for them.

## Quick Reference

- Telegram post: hook → explanation → example → takeaway → soft CTA
- Instagram carousel: cover → problem → explanation → example → practice → takeaway → CTA
- Reels hook: 1-2 lines, fast, modern, no filler
- Stories: one idea per frame, short lines, minimal clutter
- Worksheet: one topic, clear hierarchy, easy printability

## Procedure

1. Start from the user's goal, not from a template.
2. Write for one person and one platform at a time.
3. Prefer plain, concrete language over abstract marketing language.
4. Make the educational point visible with an example or contrast.
5. Keep the structure tight and readable.
6. End with a soft CTA when appropriate.

## Pitfalls

- Too generic or corporate-sounding language
- Mixing too many ideas into one post
- Making hooks too long for short-form formats
- Changing fixed brand colors or visual codes midstream
- Overloading the text with emojis or decorative noise
- Writing a polished caption that loses the user's natural voice

## Verification

Before delivering, verify that the result:
- matches the platform
- sounds natural aloud
- fits the user's teaching style
- uses examples the audience can understand
- stays on one main point
- preserves the brand voice and visual code

## Unit-to-exam workflow

Use this workflow whenever the request starts with a school textbook unit and ends with an exam task.

1. Identify the class and the actual exam: **Starlight 9 → OGE** or **Starlight 10 → EGE**.
2. Verify the current exam format and typical-error claim against official current-year sources before turning it into content.
3. Select only language with a visible exam function; do not present all unit vocabulary as equally important.
4. Build the content around application: a mini task, a Speaking response, or a Writing sentence—not a detached word list.
5. State the benefit precisely: “useful for tasks 30–36”, “for OGE word formation”, or “for an oral answer”, rather than unsupported claims about word frequency.

### Non-negotiable distinction

- **EGE:** contextual lexical choice in tasks 30–36 supports collocation, phrasal-verb and context-selection posts.
- **OGE:** grammar tasks 20–28 and word formation 29–34 need their own content logic. Do not label OGE content as an equivalent of EGE tasks 30–36.

### Voice allocation

For the core academic series, use the user’s preferred author-1 baseline: light, clear, specific and useful. Use a more playful author-2/3 energy only for lighter breaks, especially **English on Screen — How they really say it** on Friday/Saturday.
