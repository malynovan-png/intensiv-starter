# Social Content Authoring

Use when Natalie asks to write, rewrite, or adapt a post for Telegram or Instagram, especially when she gives a topic and says things like "напиши тг пост на тему...", "сделай пост для канала", or sends examples and wants the same structure reused.

This is the working skill for Natalie's English-teaching and lifestyle/social posts. It should turn loose topics into a post that matches her established rubrics and tone.

## First pass: identify the rubric

Before writing, classify the post into one of the common rubrics:

1. **Grammar post** — rules, structures, quantifiers, tenses, modal verbs, prepositions.
2. **Event / story post** — trips, museum visits, school events, personal reflections, warm storytelling.
3. **English Life post** — real-life phrases from everyday situations, one-situation vocabulary posts.
4. **Tricky phrase / idiom post** — phrases from series, idioms with a twist, misleading expressions.

If the rubric is obvious, write immediately. If it is not obvious, ask one short clarifying question and stop there.

## Core style rules

- Write in a warm, expert, conversational tone.
- Keep it clear, structured, and easy to copy into Telegram.
- Use short paragraphs and visually separated blocks.
- Prefer examples over theory.
- Use emojis lightly and intentionally.
- Keep the language lively, not academic.
- If the user prefers a mixed-language style, mirror that preference.
- For grammar posts, a polished greeting like `Hello, Darlings 💕` is acceptable when it fits the brand tone.
- Avoid awkward or unnatural examples; prefer natural-sounding English.
- Do not use tables unless the user explicitly wants one.

## Rubric workflow

### Grammar post

- Use a hook title with an emoji.
- Add a short intro.
- Break the rule into 2-4 compact blocks.
- Include examples with translations.
- End with a short takeaway / cheat sheet.
- Finish with a CTA or question.
- Add 2-3 hashtags if they fit the channel style.

### Event / story post

- Start with context: what happened, where, when.
- Keep the tone personal, warm, and sincere.
- Add one insight or educational bridge if relevant.
- Close with a reflection or invitation to respond.

### English Life post

- Start with a short title like `📱 English Life: [topic]`.
- Give 5-10 useful phrases.
- Translate every phrase.
- Add one bonus word / idiom if it helps.
- Keep it short, practical, and copy-friendly.

### Tricky phrase / idiom post

- Use a hook title.
- Show the phrase.
- Explain why it misleads beginners.
- Give the real meaning in Russian.
- Add a tiny example or dialogue.
- End with a memory anchor and a CTA.

## Validation before sending

- Does the post match the rubric?
- Is the structure clear in Telegram?
- Are the examples natural?
- Is the length appropriate for the rubric?
- Did I avoid overexplaining?
