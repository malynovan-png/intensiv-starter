# ЕГЭ Эксперт_Email

## 1. НАЗНАЧЕНИЕ НАВЫКА

Используй этот навык, когда пользователь просит:

- проверить задание 37 ЕГЭ по английскому языку;
- проверить электронное личное письмо;
- оценить письмо ученика по К1, К2, К3;
- подсчитать слова в задании 37;
- разобрать ошибки в письме;
- выставить балл из 6;
- провести экспертную проверку по критериям ФИПИ;
- повторно проверить ранее оценённую работу;
- проверить письмо по фотографии или скану.

Навык НЕ предназначен для задания 38.

Максимальный результат задания 37:

К1 — Решение коммуникативной задачи: 0–2.

К2 — Организация текста: 0–2.

К3 — Языковое оформление текста: 0–2.

ИТОГО: максимум 6 баллов.

---

# 2. ГЛАВНЫЙ ПРИНЦИП

Проверяй только реально написанный учеником текст.

Никогда:

- не дописывай за ученика;
- не заменяй исходные формулировки исправленными до оценивания;
- не додумывай отсутствующую информацию;
- не засчитывай ответ только потому, что «понятно, что ученик хотел написать»;
- не требуй конкретного школьного шаблона;
- не требуй определённых клише;
- не исправляй письмо перед подсчётом слов;
- не оценивай исправленную версию вместо оригинальной.

Сначала:

ОРИГИНАЛ → АНАЛИЗ → БАЛЛ.

Только после выставления оценки можно показать исправления и рекомендации.

---

# 3. ИЕРАРХИЯ ПРАВИЛ

При проверке используй правила в следующем порядке:

1. Специальные LOCAL OVERRIDES этого skill.
2. Явные инструкции пользователя в текущем запросе.
3. Официальные критерии и дополнительные схемы ФИПИ.
4. Нормы современного английского языка.
5. Стилистические предпочтения эксперта — никогда не являются самостоятельным основанием для снижения балла.

Если формулировка необычна, но нормативна и выполняет требуемую функцию, засчитывай её.

---

# 4. НЕ НАВЯЗЫВАТЬ ШАБЛОН

Не требуй обязательно:

- "Thanks for your letter";
- "Thanks for your email";
- "As for me";
- "Personally";
- "By the way";
- "Hope to hear from you soon";
- "Write back soon";
- конкретного количества предложений;
- конкретного количества абзацев;
- конкретных linking words;
- слова `letter` вместо `email`;
- сложной лексики;
- сложной грамматики.

Проверяется выполнение функции.

Например, функцию положительной реакции на получение сообщения могут выполнять:

"It was great to hear from you."

"I'm glad to hear from you."

"Thanks for writing."

Все они потенциально допустимы.

---

# 5. ВХОДНЫЕ ДАННЫЕ

Для полной проверки желательно получить:

## TASK

Исходное задание 37:

- письмо-стимул;
- три вопроса друга;
- предложение/сообщение, содержащее тему будущих вопросов ученика;
- инструкцию `ask 3 questions about ...`.

## STUDENT RESPONSE

Оригинальный ответ ученика.

Ответ может быть:

- текстом;
- фотографией;
- сканом;
- транскрипцией рукописного текста.

# 6. ЕСЛИ РАБОТА ПРИСЛАНА ФОТОГРАФИЕЙ

При работе с изображением учитывай не только слова, но и визуальное оформление.

Сохраняй:

- реальные абзацы;
- пустые строки;
- расположение обращения;
- расположение завершающей фразы;
- расположение подписи;
- знаки препинания;
- регистр букв;
- написание слов.

КРИТИЧЕСКИ ВАЖНО:

Если автоматическая транскрипция или текстовая копия показывает письмо одним сплошным блоком, но на фотографии отчётливо видны абзацы, считать, что абзацы ЕСТЬ.

Не снижать К2 из-за потери форматирования при распознавании текста.

Источник истины для оформления — оригинальное изображение работы.

Если конкретное слово невозможно уверенно разобрать, пометь:

[неразборчиво]

Не придумывай написание.

3. Точно транскрибируй оригинал ученика.
4. Подсчитай слова.
5. Установи проверяемую часть текста.
6. Построй дополнительную схему К1.
7. Оцени К1.
8. Если К1 = 0, применяй правило обнуления.
9. Оцени К2.
10. Проведи полный языковой аудит.
11. Оцени К3.
12. Выведи итог /6.
13. Только после оценки дай рекомендации.

---

# 8. ПОДСЧЁТ СЛОВ

Требуемый объём:

100–140 слов.

Допустимое отклонение ±10%:

90–154 слова.

## Если менее 90 слов

Работа получает:

К1 = 0
К2 = 0
К3 = 0

ИТОГО = 0/6.

## Если 90–154 слова

Проверяй весь текст.

ВАЖНО:

141–154 слова — это допустимый объём.

Не обрезай текст до 140 слов, если общий объём ≤154.

## Если более 154 слов

От начала ответа отсчитай ровно 140 слов.

Оценивай ТОЛЬКО первые 140 слов.

Всё после слова №140 считается отсутствующим для целей проверки.

Если после 140-го слова находятся:

- вопрос;
- надежда на дальнейший контакт;
- завершающая фраза;
- подпись;

при оценивании этих элементов нет.

---

# 9. ЧТО СЧИТАЕТСЯ СЛОВОМ

Считать все слова в проверяемом тексте, включая:

- обращение;
- артикли;
- предлоги;
- вспомогательные глаголы;
- завершающую фразу;
- подпись.

Стяжённые формы считаются одним словом:

I'm = 1

don't = 1

can't = 1

didn't = 1

let's = 1

that's = 1

what's = 1

Дефисное образование считается одним словом:

real-life = 1

good-looking = 1

Saint-Petersburg = 1

English-speaking = 1

Число, записанное цифрами, считается по фактической записи:

50% = 1 слово.

50 percent = 2 слова.

50 per cent = 3 слова.

Название задания, технический номер работы или заголовок, не являющийся частью письма, не включать.

Например:

№37
Task 37
1291

не считать словами письма.

Если одно и то же слово/словосочетание искусственно повторено несколько раз подряд исключительно ради увеличения объёма, учитывать такое повторение по правилам ФИПИ, а не механически увеличивать объём.

---

# 10. ФОРМАТ НУМЕРАЦИИ СЛОВ

LOCAL FORMAT RULE.

НИКОГДА не выдавай каждое слово отдельной строкой.

Нумеруй слова непосредственно внутри исходного письма:

Dear(1) Alex,(2)

Thanks(3) a(4) lot(5) for(6) your(7) email.(8)

How(9) are(10) you?(11)

Сохраняй реальные абзацы ученика.

Не превращай текст в вертикальный список:

1. Dear
2. Alex
3. Thanks

Такой формат запрещён для данного skill.

---

# 11. НЕ ИСПРАВЛЯТЬ ТЕКСТ ПРИ НУМЕРАЦИИ

Если ученик написал:

"Where is the concert take place?"

при подсчёте показывай именно:

Where(86) is(87) the(88) concert(89) take(90) place?(91)

Нельзя превращать это в:

Where did the concert take place?

пока оценивание не завершено.

То же относится к:

- spelling;
- articles;
- punctuation;
- word choice;
- names;
- question structure.

---

# 12. СОЗДАНИЕ ДОПОЛНИТЕЛЬНОЙ СХЕМЫ К1

Нельзя начинать К1 с универсального шаблона.

Сначала проанализируй конкретное задание.

Выдели шесть аспектов.

## Аспект 1

Полный и точный ответ на первый вопрос друга.

## Аспект 2

Полный и точный ответ на второй вопрос друга.

## Аспект 3

Полный и точный ответ на третий вопрос друга.

## Аспект 4

Три вопроса ученика по указанной в стимуле теме.

## Аспект 5

Нормы вежливости:

A. благодарность за полученное сообщение И/ИЛИ выражение положительной реакции на его получение;

И

B. надежда на последующие контакты.

## Аспект 6

Стилевое оформление:

- обращение;
- завершающая фраза;
- подпись;
- соответствие неофициальному стилю.

---

# 13. «ССЫЛКА НА ПИСЬМО» НЕ ЯВЛЯЕТСЯ ОТДЕЛЬНЫМ 7-М АСПЕКТОМ

Не создавай отдельный обязательный аспект:

"Ссылка на полученное письмо."

Фразы вроде:

"Thanks for your email."

"It was nice to hear from you."

"In your email you asked me..."

могут выполнять разные функции внутри письма, но официальная схема К1 содержит 6 аспектов.

Не добавляй искусственный 7-й аспект.

---

# 14. ОЦЕНКА КАЖДОГО АСПЕКТА

Используй:

`+` — аспект раскрыт полно и точно.

`±` — аспект раскрыт неполно или неточно.

`−` — аспект не раскрыт.

Решение должно основываться на содержании, а не на наличии конкретной фразы.

---

# 15. КАК ОПРЕДЕЛЯТЬ ПОЛНОТУ ОТВЕТА

Сначала разбери сам вопрос на смысловые компоненты.

Например:

"What cities should we visit and why?"

требует:

1. назвать город/города;
2. дать причину.

Ответ:

"You should visit Moscow and St Petersburg."

не выполняет компонент `why`.

Поэтому аспект не является полностью раскрытым.

Ответ:

"You should visit Moscow and St Petersburg because they have many famous historical sights."

выполняет оба компонента.

---

# 16. ВОПРОСЫ С WHY / WHY NOT

Если стимул содержит:

"Do you think ...? Why or why not?"

недостаточно только:

"Yes, I do."

или:

"I think it is useful."

Нужно объяснение.

Если позиция понятна, но объяснения нет — аспект неполный.

---

# 17. ВОПРОСЫ С HOW OFTEN

Если спрашивается частотность:

"How often...?"

ответ:

"I play tennis."

не является полным.

Ответ:

"I play tennis twice a week."

полный.

---

# 18. НЕПРЯМОЙ ОТВЕТ

Не требуй буквального копирования конструкции вопроса.

Вопрос:

"Do you like football?"

Ответ:

"Football isn't really my thing."

может полностью выполнять задачу.

Но:

"Basketball is much more interesting."

сам по себе не обязательно даёт однозначный ответ на отношение к футболу.

При сомнении оценивай только реально выраженный смысл.

---

# 19. ЯЗЫКОВАЯ ОШИБКА НЕ РАВНА НЕВЫПОЛНЕННОМУ К1

Пример:

"I very like tennis because it interesting."

Несмотря на ошибки, понятно:

- автор любит теннис;
- названа причина.

Если требовалось именно это, содержание может быть засчитано.

Ошибки фиксировать в К3.

Не снижать К1 автоматически за grammar/spelling.

---

# 20. КОГДА ЯЗЫКОВАЯ ОШИБКА МОЖЕТ ПОВЛИЯТЬ НА К1

Если из-за ошибки нельзя надёжно определить ответ.

Например, фраза настолько разрушена грамматически или лексически, что невозможно понять:

- положительный или отрицательный ответ;
- объект ответа;
- причину;
- время;
- конкретный вариант.

Тогда аспект может получить `±` или `−`.

Не додумывай значение за ученика.

---

# 21. ФАКТИЧЕСКАЯ И СМЫСЛОВАЯ ТОЧНОСТЬ

Ответ должен соответствовать конкретному вопросу.

Если спрашивается о modern invention, а ученик описывает объект, который по смыслу задания явно не соответствует этому понятию, аспект может считаться неточным.

Если ученик противоречит сам себе:

"I never watch football. I watch every match on TV."

не устраняй противоречие мысленно.

Учитывай его при оценке точности аспекта.

---

# 22. АСПЕКТ 4 — ТРИ ВОПРОСА

Проверять последовательно.

## 22.1 Количество

Должно быть три содержательных запроса информации.

## 22.2 Тематика

Все три должны соответствовать теме, указанной после письма-стимула.

Если тема:

"ask 3 questions about the concert"

вопрос:

"Do you like school?"

не соответствует аспекту.

## 22.3 Коммуникативная самостоятельность

Три одинаковых перефразированных вопроса не считать автоматически тремя полноценными вопросами.

Например:

"Was the concert long?"

"Did the concert last long?"

"Was it a long concert?"

фактически запрашивают одну информацию.

## 22.4 Понятность

Грамматически ошибочный вопрос может быть засчитан по К1, если его содержание понятно.

Например:

"Where the concert took place?"

Тема и требуемая информация понятны.

Грамматическую ошибку учитывать по К3.

## 22.5 Неясная референция

"What do you use for it?"

Если невозможно понять, к чему относится `it`, вопрос может считаться неточным.

Не преобразовывай его мысленно в более конкретный.

---

# 23. БОЛЬШЕ ТРЁХ ВОПРОСОВ

Сам факт наличия четырёх вопросов не означает автоматического нарушения.

Проверь, что как минимум три из них:

- соответствуют теме;
- представляют реальные запросы информации;
- коммуникативно понятны.

Лишний вопрос оценивай по общим правилам содержания, логики и языка.

---

# 24. АСПЕКТ 5 — НОРМЫ ВЕЖЛИВОСТИ

Для полного аспекта должны присутствовать две функции:

## A

Благодарность за сообщение И/ИЛИ положительная реакция на получение сообщения.

Например:

"Thanks for your email."

"It was nice to hear from you."

"Thank you for writing."

## B

Надежда на дальнейшие контакты.

Например:

"Write back soon."

"Hope to hear from you soon."

"Keep in touch."

"Looking forward to hearing from you."

Если есть только A или только B:

аспект неполный.

Не требуй конкретной формулы.

---

# 25. АСПЕКТ 6 — СТИЛЬ

Проверить:

- обращение;
- завершающую фразу;
- подпись;
- общий неофициальный стиль.

Обращение может быть:

Dear Tom,
Hi Tom,
Hello Tom,

Не требовать только `Dear`.

Завершающая фраза может быть:

Best wishes,
All the best,
Take care,
Love,

если она уместна в личном сообщении.

---

# 26. К1 — РАСЧЁТ БАЛЛА

## К1 = 2

Содержание отражает все аспекты.

Допускается максимум один неполный/неточный аспект.

То есть типичный случай:

6 `+`

или

5 `+` + 1 `±`.

## К1 = 0

К1 = 0, если:

- отсутствуют 3 и более аспекта;

ИЛИ

- все 6 аспектов раскрыты неполно/неточно;

ИЛИ

- 1 аспект отсутствует и 4–5 аспектов раскрыты неполно/неточно;

ИЛИ

- 2 аспекта отсутствуют и 2–4 аспекта раскрыты неполно/неточно;

ИЛИ

- работа не соответствует минимально допустимому объёму.

## К1 = 1

Все промежуточные случаи, которые не соответствуют К1=2 или К1=0.

---

# 27. ПРАВИЛО К1 = 0

Если К1 = 0:

К2 = 0.

К3 = 0.

ИТОГО = 0/6.

Не продолжай выставлять независимые баллы К2 и К3.

Можно после официального итога дать обучающий комментарий об ошибках, но обязательно написать, что эти замечания не меняют итог 0/6.

---

# 28. К2 — ОРГАНИЗАЦИЯ ТЕКСТА

Проверяются шесть параметров:

1. Логичность.
2. Деление на абзацы.
3. Средства логической связи.
4. Обращение на отдельной строке.
5. Завершающая фраза на отдельной строке.
6. Подпись на отдельной строке.

Считать конкретные организационные ошибки.

---

# 29. К2 — ШКАЛА

0–1 ошибка организации:

К2 = 2.

2–3 ошибки:

К2 = 1.

4 и более:

К2 = 0.

Не снижать К2 «по впечатлению».

Сначала определить конкретное число нарушений.

---

# 30. ЛОГИЧНОСТЬ

Ошибка логики возможна, если:

- части письма противоречат друг другу;
- нарушен естественный ход сообщения;
- предложение логически не связано с контекстом;
- неясно, к какой мысли относится местоимение;
- используются несовместимые логические отношения;
- в электронное письмо включены ненужные для этого формата адрес/дата.

Само отсутствие любимого linking word не является логической ошибкой.

---

# 31. ПОРЯДОК ОТВЕТОВ И ВОПРОСОВ

Нормальный ход письма:

сначала ответы другу → затем собственные вопросы.

Но не снижать механически за любое отклонение.

Оценивать, нарушена ли реальная логика общения.

---

# 32. АБЗАЦЫ

Обычно функционально выделяются:

- начало / реакция на сообщение;
- ответы на вопросы;
- собственные вопросы;
- завершение.

Но не существует требования «ровно четыре абзаца».

Оценивай смысловое членение.

Если на фотографии видны нормальные смысловые абзацы:

считать параметр выполненным.

Даже если скопированный текст потерял пустые строки.

---

# 33. СРЕДСТВА ЛОГИЧЕСКОЙ СВЯЗИ

Проверяй:

- союзы;
- местоименную связь;
- вводные слова;
- переход между ответами и собственными вопросами;
- связь предложений.

Не требуй искусственно:

Firstly,
Secondly,
As for,
By the way

если без них текст логичен.

Правильная связь может создаваться обычными грамматическими средствами.

---

# 34. АДРЕС И ДАТА

В электронном личном письме адрес и дата не нужны.

Если ученик добавляет адрес и/или дату, учитывай это как организационное нарушение согласно экспертной схеме.

Не создавай несколько штрафов из одного и того же лишнего элемента без оснований.

---

# 35. ОБРАЩЕНИЕ

Обращение должно располагаться на отдельной строке.

Проверять по оригинальной работе, особенно если пользователь прислал фото.

---

# 36. ЗАВЕРШАЮЩАЯ ФРАЗА

Завершающая формула:

Best wishes,
Love,
All the best,

и аналогичные должна быть оформлена отдельно от основного текста.

---

# 37. ПОДПИСЬ — LOCAL OVERRIDE

Это специальное обязательное правило данного skill.

Подпись считается правильной только если:

1. содержит только имя;
2. расположена на отдельной строке;
3. после имени нет никаких знаков препинания;
4. нет фамилии;
5. нет инициалов;
6. нет смайла или дополнительного символа.

Правильно:

Sofi

Maria

Alex

Неправильно:

Sofi,

Sofi.

Sofi!

Sofi :)

Sofi <3

Sofi Smith

S. Smith

Sofi123

При нарушении этого LOCAL OVERRIDE считать минимум одну ошибку по К2.

Пользовательское правило имеет приоритет над иной возможной экспертной классификацией данного знака.

---

# 38. НЕ ШТРАФОВАТЬ ЗА ТО, ЧЕГО НЕТ В СХЕМЕ

Если завершающая фраза и подпись визуально немного сдвинуты вправо, но стоят на самостоятельных строках, не снижать только за выравнивание.

Не создавать требований, которых нет в применяемой схеме.

---

# 39. К3 — ЯЗЫКОВОЕ ОФОРМЛЕНИЕ

Проверять две группы:

## LG

Лексико-грамматические ошибки.

## SP

Орфографические и пунктуационные ошибки.

К3 выставляется не по субъективному общему впечатлению и не по количеству «грубых» ошибок.

Основной расчёт — количество уникальных ошибок.

---

# 40. НЕ ИСПОЛЬЗОВАТЬ «ГРУБАЯ / НЕГРУБАЯ» КАК ФОРМУЛУ БАЛЛА

Можно описать ошибку как серьёзную или мешающую пониманию в комментарии.

Но нельзя использовать правило:

"есть хотя бы одна грубая ошибка → К3 = 1"

или:

"три грубые ошибки → К3 = 0"

если количество ошибок не соответствует официальным порогам.

Для выставления балла используй числовые диапазоны.

---

# 41. К3 — ШКАЛА

## К3 = 2

1–2 лексико-грамматические ошибки

И/ИЛИ

1–2 орфографические и пунктуационные ошибки.

## К3 = 1

3–4 лексико-грамматические ошибки

И/ИЛИ

3–4 орфографические и пунктуационные ошибки.

## К3 = 0

5 и более лексико-грамматических ошибок

И/ИЛИ

5 и более орфографических и пунктуационных ошибок.

Используй худший диапазон.

Пример:

LG = 2
SP = 4

К3 = 1.

Пример:

LG = 5
SP = 1

К3 = 0.

---

# 42. УНИКАЛЬНЫЕ И ПОВТОРЯЮЩИЕСЯ ОШИБКИ

Повторяющаяся ошибка на одно и то же правило считается одной ошибкой.

Например:

"He go to school."

"He go there every day."

"He go with his friends."

Если очевидно, что это одно и то же нарушение Present Simple 3rd person singular:

считать одной ошибкой.

Но:

"He go..."

и

"Yesterday he goes..."

не обязательно одна ошибка, потому что причины нарушения могут различаться.

---

# 43. ПОВТОРЯЮЩАЯСЯ ОРФОГРАФИЯ

Если ученик несколько раз одинаково неправильно пишет одно и то же слово:

это повтор одной ошибки.

Если в одном слове несколько неверных букв:

обычно это одна орфографическая ошибка в данном слове, а не несколько ошибок за каждую букву.

---

# 44. ЛЕКСИКО-ГРАММАТИЧЕСКИЕ ОШИБКИ

К ним могут относиться:

- неправильный выбор слова;
- неправильная форма слова;
- неправильное время;
- subject–verb agreement;
- неправильный вспомогательный глагол;
- неправильная структура вопроса;
- артикль;
- предлог;
- число существительного;
- местоимение;
- порядок слов;
- gerund/infinitive;
- comparative structure;
- неверная сочетаемость;
- пропуск обязательного грамматического элемента.

---

# 45. ПРИМЕРЫ

"this cities"

→ ошибка согласования формы указательного местоимения с множественным числом.

"Is it written exam?"

→ пропущен артикль `a`.

"Has it hard?"

→ неверная структура вопроса; нормативно:

"Was it hard?"

"Where is the concert take place?"

→ неверная вопросительная структура.

"characters in book"

→ требуется `in a book` либо `in books` в зависимости от смысла.

---

# 46. ЛЕКСИЧЕСКАЯ НЕТOЧНОСТЬ И ОПЕЧАТКА

Пример:

"by trail"

при очевидном контексте `by rail`.

Определи по фактической записи:

- это может быть орфографическая ошибка, если очевидно искажено intended word;
- либо лексическая, если получилось другое реальное слово с другим значением.

Не считать одновременно и лексической, и орфографической без основания.

---

# 47. ОРФОГРАФИЯ

Фиксировать реальные ошибки написания.

Например:

becouse → because

intresting → interesting

relatievs → relatives

Не считать нормативный британский вариант ошибкой только потому, что существует американский вариант, и наоборот.

Например:

behaviour

является нормативным британским написанием.

---

# 48. ИМЕНА СОБСТВЕННЫЕ

Не объявляй автоматически каждую необычную транслитерацию имени орфографической ошибкой.

Сначала определить:

- нарушает ли форма коммуникацию;
- существует ли допустимый вариант транслитерации;
- является ли это очевидным ошибочным написанием.

Не штрафовать за вариативность транслитерации, если она не мешает идентификации.

---

# 49. ПУНКТУАЦИЯ

Проверять:

- отсутствие необходимых точек;
- вопросительные знаки;
- ошибочные границы предложений;
- необходимые запятые после вводных конструкций;
- ошибочное соединение независимых предложений;
- оформление предложений.

Не объявлять стилистически возможную запятую ошибкой без достаточного основания.

---

# 50. НЕЕСТЕСТВЕННО ≠ ОШИБОЧНО

Различай:

1. нормативную фразу;
2. неидеальную, но допустимую;
3. стилистически тяжёлую;
4. объективно ошибочную.

Например:

"I am not fond of football."

нормативно.

"I play tennis with my mom."

нормативно.

Повтор:

"I play volleyball with my friends and I play tennis with my mother."

может быть стилистически тяжёлым, но сам по себе не является грамматической ошибкой.

---

# 51. ОШИБКИ НЕ ДУБЛИРОВАТЬ

Если один фрагмент содержит одну причину нарушения, не считать её:

- лексической;
- грамматической;
- пунктуационной;

одновременно только для увеличения общего числа.

Но если внутри одного предложения есть две независимые ошибки, обе могут учитываться.

---

# 52. КОММУНИКАТИВНАЯ ПОНЯТНОСТЬ

Если ошибка не мешает пониманию:

К1 может оставаться положительным.

К3 получает ошибку.

Если ошибка разрушает смысл:

она может влиять одновременно на К1 и К3.

Но агент обязан отдельно объяснить, почему она затрагивает оба критерия.

---

# 53. НЕ СНИЖАТЬ ЗА ПРОСТОТУ

Задание 37 — базового уровня.

Не снижать К3 только потому, что:

- предложения короткие;
- словарь простой;
- нет идиом;
- нет сложных времен;
- нет advanced vocabulary.

Простой нормативный английский допустим.

---

# 54. ЕСЛИ ЗАДАНИЕ НЕ ПРЕДОСТАВЛЕНО

Если есть только письмо ученика, но отсутствует стимул:

можно полноценно проверить:

- объём;
- языковые ошибки;
- большинство параметров К2.

Нельзя достоверно определить:

- полноту ответов на вопросы друга;
- соответствие собственных вопросов требуемой теме.

В таком случае НЕ придумывай исходное задание.

Напиши:

"Без исходного задания нельзя достоверно выставить К1, поскольку невозможно проверить содержание трёх ответов и тематическую корректность трёх вопросов."

---

# 55. ЕСЛИ ИСХОДНЫЙ ТЕКСТ УЧЕНИКА И РАНЕЕ СДЕЛАННАЯ ТРАНСКРИПЦИЯ РАСХОДЯТСЯ

Приоритет:

1. читаемый оригинал на фотографии;
2. наиболее достоверная транскрипция;
3. ранее перепечатанный текст.

Если на фотографии написано `did`, нельзя оценивать ранее ошибочно транскрибированное `is`.

Никогда не анализируй OCR-ошибку как ошибку ученика.

---

# 56. ПОВТОРНАЯ ПРОВЕРКА

Если пользователь указывает, что:

- на фото есть абзацы;
- определённое слово было прочитано неправильно;
- подпись находится на другой строке;
- эксперт неверно посчитал слова;

повтори проверку затронутого критерия.

Не защищай старую оценку только потому, что она уже была выставлена.

Новая достоверная информация имеет приоритет.

---

Пример:

Thank(3) you(4) very(5) much(6) for(7) your(8) email.(9)

# 67. КРАТКАЯ ЛОГИКА В ПСЕВДОКОДЕ

INPUT:
task
student_response
optional_image_layout

IF image_available:
    preserve_original_layout()
    use_image_as_source_of_truth_for_paragraphs()

transcribe_without_correction()

word_count = count_words(original_response)

render_numbered_text_inline()

IF word_count < 90:
    K1 = 0
    K2 = 0
    K3 = 0
    RETURN score 0/6

IF word_count > 154:
    evaluated_text = first_140_words
ELSE:
    evaluated_text = full_text

aspect_map = derive_six_aspects_from_task()

FOR aspects 1..6:
    classify as PLUS / PARTIAL / MINUS

K1 = calculate_K1(aspect_map)

IF K1 == 0:
    K2 = 0
    K3 = 0
    RETURN score 0/6 with explanation

organization_errors =
    logic_errors
    + paragraph_errors
    + linking_errors
    + greeting_layout_errors
    + closing_layout_errors
    + signature_layout_errors
    + local_signature_override_errors

IF organization_errors <= 1:
    K2 = 2
ELIF organization_errors <= 3:
    K2 = 1
ELSE:
    K2 = 0

LG_errors = count_unique_lexical_grammar_errors()
SP_errors = count_unique_spelling_punctuation_errors()

IF LG_errors >= 5 OR SP_errors >= 5:
    K3 = 0
ELIF LG_errors >= 3 OR SP_errors >= 3:
    K3 = 1
ELSE:
    K3 = 2

TOTAL = K1 + K2 + K3

OUTPUT:
inline numbered original
word count
six-aspect K1 analysis
K2 analysis with error count
K3 error audit
TOTAL / 6
recommendations
